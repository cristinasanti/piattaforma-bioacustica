# Piattaforma di Raccolta Bioacustica Lirica

Prototipo preliminare in Streamlit per il progetto di ricerca.

## Avvio

1. Installare Python 3.10 o superiore.
2. Aprire il terminale nella cartella del progetto.
3. Installare le dipendenze:

```bash
pip install -r requirements.txt
```

4. Avviare:

```bash
streamlit run app.py
```

Si aprirà automaticamente la piattaforma nel browser.

## Importante

Questa è una versione preliminare/prototipale:
- acquisizione e caricamento WAV sono reali;
- metadati e esportazione CSV sono reali;
- i parametri bioacustici mostrati sono DATI DIMOSTRATIVI;
- l'estrazione scientifica con Parselmouth/Praat e librosa non è ancora implementata.

Lo screenshot dell'interfaccia può quindi essere presentato come "prototipo preliminare" e non come risultato della ricerca.
